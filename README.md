# deckify — ClickOnce Distribution

This branch hosts the ClickOnce publish output for the **deckify** PowerPoint VSTO add-in.

It is auto-deployed by [`.github/workflows/publish.yml`](https://github.com/tillmannschatz/deckify/blob/development/.github/workflows/publish.yml) on every release.

## Install

Run [setup.exe](https://tillmannschatz.github.io/deckify/setup.exe).

ClickOnce will install the add-in and check this URL for updates every 7 days.

## Source

Code lives on the [`development`](https://github.com/tillmannschatz/deckify/tree/development) branch.
