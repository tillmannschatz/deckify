# deckify User Guide

This guide details every feature available in the **deckify** Ribbon tab in PowerPoint.

---

## 1. Help
*Tools for plugin information and support.*

-   **ℹ️ About**: Displays version information and copyright details.
-   **⚙️ Settings**: Configure plugin preferences (e.g., enable/disable experimental features).
-   **📝 Advanced Properties**: Opens the built-in PowerPoint Advanced File Properties dialog.
-   **⚠️ Open Log File** *(Dev Only)*: Opens the local error log file for troubleshooting plugin issues.

---

## 2. Review
*Clean up and finalize your presentation.*

-   **✨ Remove Animations**: Strips *all* animations from *all* slides in the presentation.
-   **✨ Remove Transitions**: Strips *all* slide transitions from the entire presentation.
-   **💬 Comments**: Standard PowerPoint comment controls (Pane, Delete, New) for easy access.

---

## 3. Collaboration
*Share and export your work.*

-   **📧 Mail Presentation**: Attaches the current file to a new Outlook email.
-   **📧 Mail Selected Slides**: Creates a *new* presentation containing only the selected slides and attaches it to an email.
-   **💾 Export Presentation**: Saves selected slides (or the whole deck) to a specific location/format.

---

## 4. Text
*Language and proofing tools.*

-   **abc Spelling**: Quick access to spelling and thesaurus.
-   **🌍 Language**: One-click language switching for selected text/shapes.
    -   🇬🇧 English (UK)
    -   🇩🇪 German
    -   🇫🇷 French
    -   🇺🇸 English (US)
-   **文 Translator**: Access PowerPoint's translation features.

---

## 5. Insertion
*Add rich content to your slides.*

-   **📷 Setup Screenshot**: Helper to prepare the screen for capturing.
-   **📊 Charts/SmartArt**: Quick access to standard insert galleries.
-   **🏷️ Stickers**:
    -   **On Slide**: Adds a "Sticky Note" shape *on* the slide area.
    -   **Off Slide**: Adds a "Sticky Note" shape in the grey area *outside* the slide (useful for internal notes).

---

## 6. Links (Advanced)
*Create live links between slides and objects (Master/Slave model).*

-   **🔗 New Master Link Slide**: Inserts a new slide that is linked to a "Master" slide. Updates to the master can be pulled to this slide.
-   **🔗 Edit Link**: Change the source master slide for the current slide.
-   **🔄 Update Slide**: Refreshes the current slide content to match its Master.
-   **🔗 New Object Link**: Assigns a unique ID to a selected shape, making it a "Master Object".
-   **📋 Paste Linked Object**: Pastes a copy of a Master Object. This copy is a "Slave".
-   **🔄 Update Object**: Refreshes the selected Slave object to match its Master's properties.
-   **🔄 Update All Slaves**: Updates *all* slave objects in the presentation that are linked to the selected Master.
-   **📂 Update File Location**: Updates the relative path if the source file has moved.

---

## 7. View
*Toggle common PowerPoint views.*

-   **Thumbnails**: Toggle the left-hand slide pane.
-   **Slide Master**: Switch to Master View.
-   **Slide Sorter**: Switch to Sorter View.

---

## 8. Font & Format
*Streamlined formatting controls.*

-   **Font Box**: Quick access to Font Face, Size, and standard styles (Bold, Italic, etc.).
-   **Align Text**: Left/Center/Right/Justify.
-   **Colors**: Custom color pickers for Font, Fill, and Outline.
-   **🖌️ Format Painter**: Standard format painter tool.
-   **Eyedropper**: Pick colors from screen.

---

## 9. Size & Spacing (Productivity)
*Power-user tools for precise layout.*

-   **📏 Same Height**: Resizes all selected shapes to match the *tallest* shape in the selection.
-   **📏 Same Width**: Resizes all selected shapes to match the *widest* shape in the selection.
-   **📏 Same Size**: Applies both Height and Width of the reference shape to all others.
-   **🔒 Lock Ratio**: Toggles "Lock Aspect Ratio" for selected shapes. Button state reflects the current setting.

---

## 10. Alignment
*Advanced distribution and positioning.*

-   **↔️ Distribution**:
    -   **Decrease Horizontal Gap**: Reduces space between selected objects.
    -   **Increase Horizontal Gap**: Adds space between selected objects.
    -   **Remove Horizontal Gap**: Makes selected objects touch side-by-side.
    -   *(Same controls available for Vertical spacing)*
-   **Smart Align**: Align Left/Center/Right/Top/Middle/Bottom.

---

## 11. Organize
*Layering and grouping.*

-   **Bring to Front / Send to Back**.
-   **Group / Ungroup**.
-   **Rotate / Flip**: 90-degree rotations and mirroring.
-   **Combine Shapes**: Standard Union/Intersect/Fragment tools.
-   **Selection Pane**: Toggles the visibility of the Selection Pane.
