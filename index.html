deckify

Streamline deck creation for Microsoft PowerPoint.

Install deckify

Click the button, then choose Open when your browser asks.

Power-user install (PowerShell)

Skip the browser entirely — calls VSTOInstaller directly with the Pages URL:

& "C:\Program Files\Common Files\Microsoft Shared\VSTO\10.0\VSTOInstaller.exe" /Install https://tillmannschatz.github.io/deckify/Deckify.vsto
Offline / corporate install

Download the latest deckify-X.Y.Z.7z bundle from GitHub Releases, extract the archive, and run setup.exe from inside the extracted folder. The 7z contains setup.exe, Deckify.vsto, and the Application Files folder side-by-side — ClickOnce needs all three together.

Why not just download setup.exe?

ClickOnce’s setup.exe looks for Deckify.vsto in the same folder as the EXE. If you grab just setup.exe from the GitHub Releases asset list, the manifest isn’t there and the install fails. Likewise, downloading Deckify.vsto directly from a GitHub Releases URL puts it in the wrong security zone (github.com vs the manifest’s expected tillmannschatz.github.io) — ClickOnce rejects it.

The Install button above downloads the manifest from the right origin, so it just works.
