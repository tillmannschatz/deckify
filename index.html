deckify

Streamline deck creation for Microsoft PowerPoint.

Download Installer

Single .exe — double-click and confirm the trust prompt to install.

What happens when I run the installer?

The installer is a self-extracting bundle that unpacks the ClickOnce payload to a temp folder and launches setup.exe automatically. ClickOnce shows a one-time "Microsoft Office Customization Installer" trust prompt for the publisher cert — click Install to proceed.

Subsequent updates happen silently in the background once installed (ClickOnce checks every 7 days against https://tillmannschatz.github.io/deckify/).

Power-user install (PowerShell, no download)

Installs directly from the Pages endpoint without writing to disk:

& "C:\Program Files\Common Files\Microsoft Shared\VSTO\10.0\VSTOInstaller.exe" /Install https://tillmannschatz.github.io/deckify/Deckify.vsto

Note: requires the publisher cert to already be in your Trusted Publishers store. The installer above handles that automatically via the trust prompt.

Offline / archive install

The deckify-X.Y.Z.7z archive on GitHub Releases contains the raw ClickOnce output (setup.exe, Deckify.vsto, Application Files/). Extract it and run setup.exe from inside the extracted folder — same trust prompt as the installer.
